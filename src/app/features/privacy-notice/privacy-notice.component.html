Aviso de privacidad

Consulta cada apartado antes de decidir si deseas ingresar tu DNI y utilizar Mara.

01

Responsable

La atención mediante Mara corresponde a Taller Reyes Polo, en Trujillo, La Libertad. Para consultas o solicitudes sobre datos personales, escribe a {{ privacyConfig.contactEmail }}. Este correo es provisional y está sujeto a la autorización del responsable del taller.

02

Datos y finalidad

La aplicación utiliza tu DNI para verificar tu identidad y obtiene el nombre asociado. Si decides proporcionarlos, también puede registrar teléfono, vehículo, motivo de atención y datos de citas. Se procesan los mensajes de texto o voz, las respuestas y métricas operativas para atender consultas, mantener el contexto y gestionar citas.

Este aviso no solicita autorización para mensajes publicitarios.

03

Servicios que participan

El sistema consulta API Perú durante la verificación del DNI. Según la función que utilices, pueden intervenir OpenAI para respuestas y voz, LiveKit y Simli para la experiencia de voz, y Google Calendar para sincronizar citas. El frontend y el backend están desplegados en Vercel y Railway, respectivamente.

04

Acceso y almacenamiento

El chat utiliza una sesión de cliente distinta del acceso administrativo. El navegador conserva el identificador de sesión y el nombre para mantener tu acceso hasta que cierres sesión o borres los datos del sitio. Las conversaciones, citas y métricas se registran en el sistema. Los servicios de producción se comunican mediante HTTPS.

05

Conservación y solicitudes

Los plazos de conservación del DNI, las citas y las conversaciones están pendientes de confirmación por el responsable del taller. La aplicación no tiene configurada actualmente una eliminación automática de conversaciones, citas y métricas.

Para solicitar acceso, rectificación, cancelación u oposición respecto de tus datos, utiliza el correo provisional indicado arriba. El taller deberá verificar tu identidad antes de responder a una solicitud sobre información personal.

06

Referencia normativa

Este aviso toma como referencia la Ley N.º 29733 y su Reglamento, aprobado por el Decreto Supremo N.º 016-2024-JUS. La existencia de esta pantalla no demuestra por sí sola el cumplimiento integral de esas normas ni sustituye la revisión del responsable del tratamiento.
